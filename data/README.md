# Data

`cyberbullying.xlsx` (not published) — 4,241 Facebook comments written in Syrian-dialect Arabic, each labeled with one of 13 categories (0 = not bullying, 1–12 = bullying types; see the main README).

The raw comments come from real social media users, so they are kept out of this public repository.
To re-train the models, place the file here and run `python train.py`.
